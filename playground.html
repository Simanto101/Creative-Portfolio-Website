How to read this page

Honest labels, on purpose.

Live means liveIf a badge says live or working, the system runs today and is in real use.
Demo means demoWorking demos run on fictional data, built so the full flow can be shown in one meeting.
Concept means conceptConcepts are designed, not built. They are badged as concepts so nobody mistakes them for products.
