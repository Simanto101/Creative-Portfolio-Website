# Simanto Mitro — Creative Portfolio Website

A high-performance, scroll-driven interactive portfolio website featuring seamless video synchronization, GSAP ScrollTrigger, Lenis momentum physics, and glassmorphic UI.

## Tech Stack
- **Core**: HTML5, Vanilla CSS3, JavaScript (ES6+)
- **Animation**: GSAP 3 + ScrollTrigger
- **Scroll Engine**: Lenis Smooth Momentum Scroll
- **Typography**: Google Fonts (Instrument Serif, Unbounded, Inter)
- **Forms**: Netlify Forms with custom interactive states

## Deployment
- **Netlify**: Connect repository or drag-and-drop root folder directly to [Netlify Drop](https://app.netlify.com/drop).
- **Vercel**: Import repository via [Vercel](https://vercel.com).
- **GitHub Pages**: Enable under **Settings** > **Pages** > Branch `main`.
